Moved the `overture-schema validate` command, and the input loading and error reporting behind it, into this package as `overture.schema.validation.command`; the command's output, flags and exit codes are unchanged. The package now depends on `click`, `rich`, `pyyaml` and `yamlcore`, and no longer on `overture-schema-common`. `validate()` and `validate_json()` build their union through `overture-schema-system`: a model whose `type` field is `Literal[None]` or a multi-value literal now joins as a plain union member instead of raising `TypeError` or discriminating on its first value.
