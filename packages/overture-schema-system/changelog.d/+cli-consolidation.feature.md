Added `overture.schema.system.discovery.model_union`, which combines a `ModelDict` into one type for a Pydantic `TypeAdapter` (a union discriminated on `type` for `overture`-tagged models, with every other model as a plain member), and `typing_util.single_literal_value` / `literal_values` / `is_newtype`. The CLI and `overture-schema-validation` now share this union builder instead of each carrying a copy.
